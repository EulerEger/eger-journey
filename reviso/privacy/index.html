Privacy Policy#

This website is a static, read-only publication.

What data is collected#

  • No cookies are used
  • No third-party tracking scripts are embedded
  • No browser fingerprinting is performed

Contact form#

If you use the contact form:

  • Your name, email address, and message are stored for no more than 2 weeks.
  • Data is stored locally on the server
  • Data is used only to respond to your message
  • Data is never shared with third parties

Server logs#

Basic web server logs may record:

  • Requested page
  • Timestamp
  • IP address (temporarily, for security purposes)

Logs are rotated and retained for a limited time.

Your rights#

You may request deletion of your contact message by contacting the site administrator.
