Introduction#

Python is a programming language object-oriented, which means that an object is simply a collection of data (variables) and methods (functions). More precisely, we create a class that is a blueprint for that object.

Let’s explain objects and clsses by building a class called particle.

class particle():
    def __init__(self,x,y,z,vx,vy,vz,m):
        self.x = x
        self.y = y
        self.z = z
        self.vx = vx
        self.vy= vy
        self.vz = vz
        self.m = m

The __init__ function is a special function that is called when the class is being initiated. It is used for assigning values in class. self is an instance that allow to store a defined attribute in the class.

class particle():
    def __init__(self,x,y,z,vx,vy,vz,m):
        self.x = x
        self.y = y
        self.z = z
        self.vx = vx
        self.vy= vy
        self.vz = vz
        self.m = m   
    def move(self,t):
        self.x = self.x+ self.vx * t
        self.y += self.vy * t
        self.z += self.vz * t
    def get_distance(self):
        return np.sqrt(self.x**2+self.y**2+self.z**2)

inheritance and polymorphism#

As Python is object-oriented we can create new classes from an existing class which we will call the parent class and those that are derived will be the child class. Let’s create a child class called proton from the particle class as we know that a proton is a particle with positive charge. Therefore:

  • A proton has all the characteristics of a particle.
  • A proton has unique traits that are separate from a particle.

This is precisely what class inheritance allows us to play with.

  • A child (proton) class inherits all the traits of its parent (particle). Furthermore, the child may have separate traits from its parent.

The polymorphism is a very important concept in Object-Oriented Programming.

class Proton(Particle):
    def __init__(self,x,y,z,vx,vy,vz):
        self.q = 1.6e-19
        self.m = 9.11e-31
        super(Proton, self).__init__(x,y,z,vx,vy,vz,self.m)
    def move(self, t, Ex, Ey, Ez):
        self.x += self.vx * t + (1/2)*(self.q/self.m)*Ex*t**2
        self.y += self.vy * t + (1/2)*(self.q/self.m)*Ey*t**2
        self.z += self.vz * t + (1/2)*(self.q/self.m)*Ez*t**2
        self.vx += (self.q/self.m)*Ex*t
        self.vy += (self.q/self.m)*Ey*t
        self.vz += (self.q/self.m)*Ez*t
    def get_position(self):
        return np.array([self.x, self.y, self.z])
    def get_velocity(self):
        return np.array([self.vx, self.vy, self.vz])
p = Proton(0,0,1,1,0,0)
p.move(t=2,Ex=4e-12,Ey=3e-12,Ez=6e-12)
print(p.get_position())
p.move(t=2,Ex=4e-12,Ey=3e-12,Ez=6e-12)
print(p.get_position())
